# GitHub release checklist

- [x] Linux setup and launcher are documented.
- [x] Windows x64 PowerShell setup and launcher are documented.
- [x] Model files, compiled runtimes, build trees, and downloads are ignored.
- [x] Default server binding is localhost only.
- [x] Setup scripts avoid administrator commands and system package managers.
- [ ] Choose and add a license for the scripts and documentation.
- [ ] Review the Qwen model license and llama.cpp license before redistribution.
- [ ] Test `setup_qwen.ps1` end to end on a clean Windows x64 computer.
- [ ] Add SHA-256 verification for downloaded model/tool archives.
- [ ] Confirm that no model weights or compiled binaries are staged in Git.
